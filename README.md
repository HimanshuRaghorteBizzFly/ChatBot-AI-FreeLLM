# 🤖 AI ChatBot & Vision Studio

🌐 **[Live Demo – Try AI ChatBot](https://chatbot-ai-freell.streamlit.app/)**

A multi-model AI chatbot and image generator built with **Python and Streamlit**, featuring AI conversations, image generation, and customizable dark/light themes.

## ✨ Features

- 🤖 **Multi-LLM Support:** NVIDIA Nemotron, Google Gemini, Groq, Ollama, and Free AI.
- 🎨 **AI Image Generation:** Microsoft MAI-Image with image downloads.
- ⚡ **Real-Time Streaming:** Fast, interactive AI responses.
- 🧠 **Thinking Process:** Reasoning trace visualization.
- 🌙 **Dark & Light Mode:** Customizable interface.
- 🔑 **API Key Manager:** Manage multiple AI provider keys.
- 💬 **Interactive Chat:** Simple, responsive Streamlit interface.

## 🛠️ Tech Stack

**Frontend:** Streamlit, Python, CSS

**Backend:** Python, AI APIs

**AI Providers:** Google Gemini, NVIDIA, Groq, OpenRouter, Ollama

## 🚀 Installation

```bash
git clone https://github.com/HimanshuRaghorteBizzFly/ChatBot-AI-FreeLLM.git
cd ChatBot-AI-FreeLLM
python -m pip install -r requirements.txt
python -m streamlit run Frontend.py
```

## 🔑 API Configuration

Create a `.env` file:

```env
OPENROUTER_API_KEY=your_key
GEMINI_API_KEY=your_key
GROQ_API_KEY=your_key
OLLAMA_API_KEY=your_key
```

Keep API keys private and never commit `.env` to GitHub.
